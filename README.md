# 🎮 BilimQuest — геймифицированный образовательный портал

**BilimQuest** — веб-платформа для изучения информатики в 5 классе на казахском языке. Учебная программа разбита по четвертям (тоқсан) на модули и мини-игры: ученики зарабатывают баллы и звёзды, соревнуются в рейтинге, а учитель управляет доступом к играм и следит за прогрессом класса. Встроенный ИИ-ассистент **BilimAI** (на базе Claude API) помогает ученикам разбираться в темах, не выдавая готовых ответов, а учителю — анализировать успеваемость.

## ✨ Возможности

### Для ученика
- 📚 **Учебные модули по четвертям** — темы информатики: информация и кодирование, двоичная система, компьютерная графика, робототехника, кибербезопасность.
- 🕹️ **10+ мини-игр и квестов** с начислением баллов и звёзд за прохождение.
- 🏆 **Рейтинг класса** — таблица лидеров по набранным баллам.
- 👤 **Личный профиль** с историей прохождения и результатами.
- 🤖 **Чат с BilimAI** — подсказки по заданиям (наводящие вопросы вместо готовых ответов) и советы по учёбе и самоорганизации.

### Для учителя
- 📊 **Панель учителя** — прогресс всех учеников класса, детальная страница по каждому ученику.
- 🔓 **Управление доступом** — открытие игр и сброс результатов модулей для пересдачи.
- 📢 **Объявления** для класса с историей и редактированием (время — Asia/Almaty).
- 🧠 **ИИ-панель учителя**:
  - аналитика успеваемости класса;
  - выявление отстающих учеников (at-risk);
  - генерация плана урока;
  - отчёт для родителей по конкретному ученику.
- 📄 **Методические материалы** — инструкции для учителя в PDF.

## 🛠️ Технологии

| Слой | Стек |
|---|---|
| Backend | Python 3.10–3.11, Flask 3, SQLAlchemy 2, Flask-Migrate (Alembic) |
| База данных | PostgreSQL (production, Railway) / SQLite (локально) |
| Frontend | Jinja2, HTML/CSS/JS (кастомные стили под каждую игру) |
| ИИ | Anthropic Claude API (`claude-haiku-4-5` — чат, `claude-sonnet-4-6` — аналитика) |
| Деплой | Railway, Gunicorn, Docker |

### Модели данных

- `Student` — ученик (имя, фамилия, класс, баллы), уникальность по имя+фамилия+класс;
- `Teacher` — учитель (email + пароль);
- `Task` / `StudentProgress` — задания модулей и ответы учеников;
- `GameProgress` — результаты игр (баллы, звёзды, номер попытки);
- `GameAccess` — доступ ученика к играм (открывает учитель);
- `Announcement` — объявления для класса.

## 🚀 Запуск локально

```bash
# 1. Клонировать репозиторий
git clone <repo-url>
cd Flask-App-Railway

# 2. Создать виртуальное окружение
python -m venv venv
venv\Scripts\activate        # Windows
# source venv/bin/activate   # Linux/macOS

# 3. Установить зависимости
pip install -r requirements.txt

# 4. Создать файл .env (см. переменные ниже)

# 5. Запустить
python main.py
```

Приложение доступно на `http://localhost:5000`. Таблицы создаются автоматически при первом запуске (`db.create_all()`).

Создать учётную запись учителя:

```bash
python create_teacher.py
```

## ⚙️ Переменные окружения

| Переменная | Обязательная | Описание |
|---|---|---|
| `SECRET_KEY` | да (в проде) | Ключ подписи сессий Flask |
| `DATABASE_URL` | да | Строка подключения PostgreSQL (`postgres://` автоматически переписывается в `postgresql://`) |
| `ANTHROPIC_API_KEY` | для ИИ-функций | Ключ Anthropic API для BilimAI и ИИ-панели |
| `AI_CHAT_ENABLED` | нет | `true` — включить чат BilimAI (по умолчанию выключен) |

Пример `.env`:

```env
SECRET_KEY=your-secret-key
DATABASE_URL=postgresql://user:password@host:5432/dbname
ANTHROPIC_API_KEY=sk-ant-...
AI_CHAT_ENABLED=true
```

## ☁️ Деплой на Railway

1. Создайте проект на [Railway](https://railway.app) и подключите репозиторий.
2. Добавьте плагин **PostgreSQL** — Railway сам пропишет `DATABASE_URL`.
3. В настройках сервиса задайте `SECRET_KEY`, `ANTHROPIC_API_KEY`, `AI_CHAT_ENABLED`.
4. Запуск выполняется через `Procfile`:

```
web: gunicorn wsgi:app
```

Пул соединений настроен под Railway-прокси (`pool_pre_ping`, `pool_recycle=280`, `sslmode=require`), поэтому приложение переживает разрывы простаивающих соединений.

### Docker (альтернатива)

```bash
docker build -t bilimquest .
docker run -p 5000:5000 --env-file .env bilimquest
```

## 🔐 Роли и доступ

- Ученик регистрируется сам (имя, фамилия, класс, пароль) и входит через `/login`.
- Учитель входит через `/login_teacher`; регистрация учителя — через `/register_teacher` или скрипт `create_teacher.py`.
- Маршруты защищены декоратором `login_required(role)` с разделением по ролям.
